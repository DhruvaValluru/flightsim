## approaches
- (a) New separate check `tight_box_present` vs (b) extend box_vs_mask. (b) keeps seven gates but mixes a mask-free condition into a mask-reading gate and cannot run when the mask is missing. Chosen (a): independent, named failure, and the report then lists eight rows with the seven still intact.
- Pin values: (a) hard-coded constants in the test vs (b) GOLDEN.json beside the fixture. Chosen (b): Windows commits data, mac test code is final today.
- Fixture: whole run vs hand-trimmed files. Chosen whole minimal run, so verify_run itself can be run on it in the test (tolerance for the ranges, exact for the pixel box).
