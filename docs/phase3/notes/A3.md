## approaches
- **Where the PS side reads the pin.** (a) a literal `$pin = "5.5"` in each script: third copy of the constant, drifts. (b) read `ue/FlightSim.uproject` `EngineAssociation` via `ConvertFrom-Json`: already A2's edited file, and `test_platform.py:292` already asserts uproject == `UE_ENGINE_VERSION`, so PowerShell and Python agree by test. (c) call Python: needs a venv at build time, rejected. **Chosen: (b), through one function `Get-PinnedEngine` in the helper**, so B2 swaps its body to read `scripts/toolchain.json` (one place, no script edits). Patch level: compare major.minor only (refusal), and print the full `5.5.4`; a patch differing from `UE_ENGINE_PATCH` is a printed note, not a refusal (A1 records the patch in docs/TOOLCHAIN.md; refusing on patch would break the first engine hotfix).
- **Shared helper vs inline in both scripts.** Inline is 2 copies of ~12 lines (the scripts are already twins). Helper: one copy, one test target. Chosen: helper. Cost: dot-sourcing path `$PSScriptRoot\ue_engine.ps1`.
- **Test location.** `tests/test_platform.py` is about the Python dispatch and its one pin test; `tests/test_powershell_scripts.py` owns `SCRIPTS`/`code_lines`. Chosen: the latter.
