# A4 · A stale engine binary is refused (R4)

## goal
- **Do:**
  - After a successful build, write `ue/Plugins/FlightSimBridge/Binaries/build_stamp.json` with the engine version and a hash of the plugin's `Source/` tree.
  - Before any render, compare it with the current source. A missing or different stamp refuses with `engine.binary_stale`, naming both hashes.
  - The launcher (E6) uses the same stamp to decide whether to rebuild.
- **Verify:**
  - Container: `pytest -q -k binary_stale`. A synthetic stamp with a wrong hash refuses; a matching one passes.
  - Windows: touching one `.cpp` without rebuilding makes the next render refuse.

## approaches
- A. Hash only file contents, sorted. Cheap, but renames/moves go undetected. Rejected.
- B. Hash `relpath NUL sha256(content) LF` per file, sorted; CRLF normalised to LF. Detects renames, immune to git autocrlf differences between Mac and Windows checkouts. **Chosen.**
- C. Use file mtimes (like UBT). Not portable, false stale after a git checkout. Rejected.
- Where to check: (i) only in capture.py; (ii) only in runs.py; (iii) one helper in platform.py called from both. Chosen (iii), so E6 can import the same helper.

## coding_plan
Hash spec (identical in both languages):
- Root: `<repo>/ue/Plugins/FlightSimBridge/Source`. Files: every regular file under it, recursively, no exclusions (no Intermediate/ lives there).
- Path key: path relative to the root, `/` separators, no leading `./`; paths are ASCII (Python sorts by code point, PowerShell uses `[StringComparer]::Ordinal`).
- Order: ascending by path key.
- Content: raw bytes with every `\r\n` replaced by `\n` (lone `\r` kept); no BOM stripping.
- Per-file line: UTF-8 bytes of `<path key>` + `\0` + lowercase hex sha256(normalised content) + `\n`.
- Tree hash: lowercase hex sha256 of the concatenation of the lines in order.
- Stamp JSON: `{"stamp_version":1,"engine_version":"5.5.4","source_sha256":"<hex>","built_utc":"<iso>"}`. `engine_version` is read from `<UE_ROOT>\Engine\Build\Build.version` (Major.Minor.Patch). The check compares `source_sha256` exactly and the engine major.minor to the pin `UE_ENGINE_VERSION` [exists core/util/platform.py:142].
