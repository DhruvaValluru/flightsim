## approaches
- A. Fix only the message (mac-only). Cheap, but leaves the review failure; verify requires a working run, so rejected as sole approach.
- B. Reproduce first, then fix the real cause and make the message name it (chosen). The review document is missing, so a guess at the cause would be fabrication; reproduction costs one Windows run and decides between engine fix and recording.
- C. Latch the elevator unconditionally now without reproducing. Correct in itself and small, but it does not explain a commandlet crash and risks changing determinism baselines; do it in step 5 only if step 2 implicates it (or record it per the plan).
- Flag handling: keep `--no-host-flight` as an argparse option marked developer-only (E1 later hides/gates it); chosen over deleting it because tests and `core/dataset/batch.py` rely on it.
