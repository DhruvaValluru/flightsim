## approaches
- A. One universal lock generated on the Mac with Python 3.11, committed. pip-compile pulls hashes for all wheels the index offers (all platforms, all cp tags) for each pinned version, so one file serves the three OSes. Platform-only deps carry markers. Trade-off: the lock is only valid for the Python version it was resolved on (markers evaluated at 3.11), but since all packages are exact pins in requirements.txt the version set barely varies. Chosen: simplest, matches the plan.
- B. Per-OS locks (`requirements-linux.lock` etc.). Trade-off: guarantees resolution per platform but triples files, B3's "lock covers requirements.txt" check and the installer logic. Rejected.
- C. `pip-compile --universal` via uv. Better marker coverage, but adds a new tool and the plan names pip-compile. Rejected.
- Python-version choice: generate on 3.11 (CI) -- chosen; the installer's 3.12 venv uses the same pins and hashes, as the wheels exist for cp311 and cp312.
