Helpers [new]:
- `_read_toolchain() -> dict`: `json.loads` of `REPO / "toolchain.json"`
- `_include_order(path: Path) -> str`: regex `EngineIncludeOrderVersion\.Unreal(\d+)_(\d+)` on the text, returns `"5.7"`
- `_requirement_names_and_specs(path: Path) -> dict[str, str]`: skips blank, `#`, `-r`/`-c` and option lines; canonical name -> specifier string
- `_lock_pins(path: Path) -> dict[str, str]`: for pip-compile `--generate-hashes` output, a line `name==version \` begins an entry (continuation lines `--hash=sha256:...` and `# via ...` comments are skipped); canonical name -> version; extras like `name[extra]==v` reduce to name
Tests [new]:
- `test_engine_pin_is_one_value_in_every_file`: collects `{"toolchain.json": engine.version, "ue/FlightSim.uproject": EngineAssociation, "ue/Source/FlightSim.Target.cs": ..., "ue/Source/FlightSimEditor.Target.cs": ..., "core/util/platform.py UE_ENGINE_VERSION": plat.UE_ENGINE_VERSION}`; assert one distinct value; the message lists every file with its value (names the odd one); the same test also asserts `engine.patch == plat.UE_ENGINE_PATCH` (the patch is the pin's companion per A2 and decision 13), naming toolchain.json and platform.py

Lock format assumed: `pip-compile --generate-hashes` (`name==ver \` plus `--hash=` lines). requirements-dev.txt is not covered (B1 decides; B3 checks it only if `requirements-dev.lock` exists)
