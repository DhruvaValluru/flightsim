## approaches
- A. Put weights in the generated XML via `a4_sync.py` default stations (physics always includes the loadout). Trade-off: every A-4 run is loaded, no clean-aircraft option; but picture and physics cannot disagree. 
- B. Leave XML at 0 and apply the loadout at run time through `core/scenario/loading.py` properties. Trade-off: clean aircraft stays available, but a run that omits the loadout draws stores with 0 lb (the disagreement the plan forbids).
- C. Both: XML default carries the loadout (A), `loadout.enabled` toggle in config lets a clean card write 0. Not chosen now (extra surface).
- Chosen: A, since owner decision 2 calls it the "default loadout" and C2 draws it every time; the refusal in the loader guards picture-vs-physics drift.
