## approaches
- A. Per-station isolated envs (REST_ENV + that station's vars), diff against REST by `Part.index`. Trade-off: each component is exactly one station's parts; a part gated on a combination of stations would be missed, so the test also asserts sum(per-station) == full-set delta. CHOSEN: matches the plan wording and decision 2's measurement method (one variable at a time).
- B. One full-loadout env, then assign added parts to stations by x/y position. Trade-off: no per-variable evaluation, but a position heuristic can mis-assign (STA2/STA4 are mirror images at x=-1.9/+1.9 m) and is not what the decode measured.
- C. Mesh stale rule: bump the shared version to 4 for every aircraft (forces all re-converts) vs an A-4-only rule. CHOSEN: A-4 only, because other airframes have no components and a global bump forces needless re-conversion of each with a FlightGear tree fetch.
