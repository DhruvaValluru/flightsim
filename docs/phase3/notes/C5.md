## approaches
- A. Add `children=` to `measure_object` and compute on the id set (chosen). Small, keeps one counting function the verifier can mirror, default empty keeps all old behaviour.
- B. Relabel the mask beforehand (map child ids to the parent id) then call `measure_object` unchanged. Simple, but it destroys the children's own pixels, so a component could not be measured from the same mask and `occluded_by` could not tell payload from fuselage.
- C. Engine paints parent+child with one id. Rejected: contradicts the Phase C preamble (components have their own `int_id`) and needs C++.
- Component record: separate `component_label_record` (chosen) vs a third branch in `object_label_record`; separate function keeps the aircraft path byte-identical (the primary copies `base_labels`), so a regression test is trivial.
