- The page: one button `id="run"` labelled "Run" (index.html:245), `disabled` until a compile returns a valid verdict (`renderVerdict`, index.html:614/630); `startRun` (:1754) posts `{spec: editedSpecDict(), provenance: {compiler: compiled.compiler,...}}` and would throw on `compiled == null`. Click wiring :1752.
- `/compile` refuses an empty prompt (server.py:329-330). `clip_seconds` and `environment` are CompileRequest fields (server.py:135-146); the same two edits exist as code only in compile_endpoint (:394 clip, `apply_environment_preset` D4).
- Mac/headless contradiction: runs.py:2731-2746 captures headlessly when `not ue_available()` and the spec has cameras, but `run_endpoint` refuses `ue.platform` for ANY spec before `manager.start` (server.py ~1120-1127, `if not ue_available()`). So a camera spec can never reach the headless path via /run. On a Mac `ue_available()` is True (core/util/platform.py:321-331) so the Mac does not take the headless branch at all; headless is the Linux/no-engine-Windows case and tests monkeypatch it.
- `provision_place(spec)` (runs.py:746) is called first in `run_endpoint` (decision 17) and gives the grand_canyon bake lookup; the default spec must go through it unchanged.
- Loadout is already in `assets/aircraft_config/A4.json` `loading.loadout` (stations STA2/3/4 = 750.0, model_vars STA2/3/4_LOAD=1); `LoadingSpec.payload` is {station: kg} (core/scenario/blocks.py:575-600).
- Plan line numbers are current for server.py:146/984 and runs.py:826/845/1316/746.

## approaches
- A. Server builds the default spec when the body is empty (chosen). One source of truth, headless-testable, the page just posts `{}`.
- B. The page calls `/compile` with a canned prompt then `/run`. Fewer server changes but needs the LLM/regex round trip, an empty prompt is still refused, and "POST /run {}" would stay 422, so the Verify cannot pass.
- C. A named default scenario file in examples/. Another file to keep in sync with decisions 2/7/4; rejected.
Within A, the spec is built by the regex `compile_prompt` plus explicit edits (chosen) rather than hand-assembling every Quantity, so field provenance and defaults stay the compiler's.
