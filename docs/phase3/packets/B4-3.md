  draw `M_VertexColor` (one stated grey, `SceneSyntheticTerrainGrey` 0.5)

  `M_VertexColor` under `FLIGHTSIM_REBUILD_MATERIALS=M_VertexColor` (it
  cannot join `GRAPH_GENERATIONS`, which a Mac test pins to five names).
  The runner rebuilt it on MAIN after the merge.
